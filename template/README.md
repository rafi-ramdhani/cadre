# {{name}}

A cadrei: Claude Code member sessions, run by one orchestrator, working on your projects.

- `playbook.md`: teams, pipelines and routing rules (the orchestrator reads it every session)
- `projects.yaml`: every project, by its repository
- `members/<team>/<role>.md`: one member per file
- `teams/<team>/`: notes and outputs of teams without a project
- `cadrei.conf`: settings such as the member permission mode

To change any of it, ask the orchestrator.
