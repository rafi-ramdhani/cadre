# Cadrei

## Writing for users

User-facing text is the README, docs/guide.md, CHANGELOG.md, SECURITY.md, CONTRIBUTING.md and anything the program prints.

- Write the way a friendly developer talks to a peer: casual, "you", contractions, short sentences.
- Use plain everyday words and no jargon. When a term has to stay, because it is the real name of something (a tool, a command or a file), explain it in a few plain words the first time it appears.
- Never use em dashes.
